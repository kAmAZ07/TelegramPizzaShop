# Детальное руководство по решению задач по Теории Вероятностей для контрольной работы

**Цель:** Предоставить пошаговые алгоритмы и конкретные формулы для решения типовых задач, встречающихся в семинарских материалах, с акцентом на контекст, известные параметры и искомые величины.

## I. Задачи на классическое и геометрическое определение вероятности

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Классическое определение** (Подбрасывание монет, костей, выбор шаров) | Описание эксперимента, общее число элементов ($N$), число элементов с нужным свойством ($K$). | Вероятность события $A$ ($P(A)$). | 1. Определить общее число исходов $n$. 2. Определить число благоприятных исходов $m$. 3. Применить классическое определение. **(Семинар 6, Задача 1, 2)** | $P(A) = \frac{m}{n}$ |
| **Гипергеометрическое распределение** (Выбор без возвращения) | Общее число элементов ($N$), число элементов типа 1 ($K$), число элементов типа 2 ($N-K$), размер выборки ($n$), число элементов типа 1 в выборке ($k$). | Вероятность получить ровно $k$ элементов типа 1. | Использовать формулу сочетаний для общего числа исходов и числа благоприятных исходов. **(Семинар 4, Задача 1)** | $P(k) = \frac{C_K^k \cdot C_{N-K}^{n-k}}{C_N^n}$ |
| **Геометрическая вероятность** (Точка наудачу) | Область $G$ (отрезок, площадь, объем), подобласть $g$. | Вероятность попадания в подобласть $g$. | 1. Найти меру (длину, площадь, объем) $\mu(G)$. 2. Найти меру $\mu(g)$. 3. Применить геометрическое определение. **(Семинар 6, Часть 2, Задача 1)** | $P(A) = \frac{\mu(g)}{\mu(G)}$ |

## II. Задачи на условную вероятность и формулы Байеса

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Условная вероятность** | Вероятность совместного события $P(A \cap B)$, вероятность условия $P(B)$. | Условная вероятность $P(A|B)$. | Применить прямое определение условной вероятности. **(Семинар 3)** | $P(A|B) = \frac{P(A \cap B)}{P(B)}$ |
| **Формула полной вероятности** | Полная группа несовместных гипотез $H_i$, их вероятности $P(H_i)$, условные вероятности $P(A|H_i)$. | Вероятность события $A$ ($P(A)$). | Просуммировать вероятности события $A$ по всем гипотезам. **(Семинар "Полнаявероятность...")** | $P(A) = \sum_{i} P(A|H_i) \cdot P(H_i)$ |
| **Формула Байеса** | То же, что и для полной вероятности. | Апостериорная вероятность гипотезы $P(H_k|A)$. | 1. Найти $P(A)$ по формуле полной вероятности. 2. Применить формулу Байеса. **(Семинар "Полнаявероятность...")** | $P(H_k|A) = \frac{P(A|H_k) \cdot P(H_k)}{P(A)}$ |

## III. Задачи на схему Бернулли и предельные теоремы

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Схема Бернулли** (Малое $n$) | Число испытаний $n$, вероятность успеха $p$, число успехов $k$. | Вероятность ровно $k$ успехов ($P_n(k)$). | Применить формулу Бернулли. | $P_n(k) = C_n^k p^k (1-p)^{n-k}$ |
| **Приближение Пуассона** | $n$ велико, $p$ мало ($np < 10$), $\lambda = np$. | Вероятность ровно $k$ успехов ($P_n(k)$). | Использовать распределение Пуассона. **(Семинар 4, Задача 3)** | $P_n(k) \approx \frac{\lambda^k}{k!} e^{-\lambda}$ |
| **Интегральная теорема Муавра-Лапласа** | $n$ велико ($npq \ge 10$), $p$ не мало, интервал $[k_1, k_2]$ или отклонение $\epsilon$. | Вероятность попадания числа успехов в интервал $P(k_1 \le k \le k_2)$. | 1. Вычислить $np$ и $\sqrt{npq}$. 2. Нормировать границы $x_i = \frac{k_i - np}{\sqrt{npq}}$. 3. Использовать функцию Лапласа $\Phi(x)$. **(Семинар 4, Задача 5)** | $P(k_1 \le k \le k_2) \approx \Phi(x_2) - \Phi(x_1)$ |

## IV. Задачи на дискретные случайные величины (СВ)

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Построение распределения** | Описание эксперимента (например, бросок кости, остаток от деления). | Ряд распределения $\begin{pmatrix} x_i \\ p_i \end{pmatrix}$. | 1. Определить все возможные значения $x_i$ СВ. 2. Найти вероятность $p_i$ для каждого $x_i$. 3. Проверить условие $\sum p_i = 1$. **(Семинар 6, Задачи на остаток)** | $P(X=x_i) = \sum_{\omega: X(\omega)=x_i} P(\omega)$ |
| **Числовые характеристики** | Ряд распределения $\begin{pmatrix} x_i \\ p_i \end{pmatrix}$. | $M[X]$, $D[X]$, $\sigma[X]$. | Применить формулы для дискретных СВ. | $M[X] = \sum x_i p_i$ <br> $D[X] = \sum x_i^2 p_i - (M[X])^2$ |
| **Функция распределения** | Ряд распределения $\begin{pmatrix} x_i \\ p_i \end{pmatrix}$. | Функция распределения $F(x)$. | Построить ступенчатую функцию, где скачок в точке $x_i$ равен $p_i$. | $F(x) = \sum_{x_i < x} p_i$ |

## V. Задачи на непрерывные случайные величины (СВ)

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Нахождение константы** | Плотность распределения $f(x)$ с неизвестной константой $C$. | Константа $C$. | Использовать условие нормировки. | $\int_{-\infty}^{\infty} f(x) dx = 1$ |
| **Вероятность попадания в интервал** | Плотность $f(x)$ или функция распределения $F(x)$. | $P(a \le X < b)$. | Использовать интеграл от плотности или разность значений $F(x)$. | $P(a \le X < b) = \int_a^b f(x) dx = F(b) - F(a)$ |
| **Числовые характеристики** | Плотность распределения $f(x)$. | $M[X]$, $D[X]$. | Применить формулы через интегралы. | $M[X] = \int_{-\infty}^{\infty} x f(x) dx$ <br> $D[X] = \int_{-\infty}^{\infty} x^2 f(x) dx - (M[X])^2$ |
| **Преобразование СВ** | Плотность $f_X(x)$, преобразование $Y = g(X)$ (например, $Y=X^3$, $Y=\sqrt{X}$). | Плотность $f_Y(y)$. | 1. Найти обратную функцию $x = h(y) = g^{-1}(y)$. 2. Найти производную $|h'(y)|$. 3. Применить формулу. **(Семинар 6, Задачи на равномерное)** | $f_Y(y) = f_X(h(y)) \cdot |h'(y)|$ |

## VI. Задачи на системы случайных величин (X, Y)

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Маргинальное распределение** (Непрерывный случай) | Совместная плотность $f(x,y)$. | Маргинальная плотность $f_X(x)$ (или $f_Y(y)$). | Проинтегрировать совместную плотность по "лишней" переменной. **(Семинар 9, Задача 3)** | $f_X(x) = \int_{-\infty}^{\infty} f(x,y) dy$ |
| **Маргинальное распределение** (Дискретный случай) | Таблица совместного распределения $P(x_i, y_j)$. | Маргинальный закон $P(X=x_i)$. | Просуммировать вероятности по строкам (для $X$) или столбцам (для $Y$). **(Семинар 9, Задача 1)** | $P(X=x_i) = \sum_j P(x_i, y_j)$ |
| **Математическое ожидание произведения** | Совместная плотность $f(x,y)$ или таблица $P(x_i, y_j)$. | $M[XY]$. | Использовать формулу для $M[g(X,Y)]$. **(Семинар 9, Задача 3)** | $M[XY] = \iint x y f(x,y) dx dy$ <br> $M[XY] = \sum_i \sum_j x_i y_j P(x_i, y_j)$ |
| **Ковариация и корреляция** | $M[X], M[Y], D[X], D[Y], M[XY]$. | Ковариация $\text{Cov}(X,Y)$, коэффициент корреляции $\rho(X,Y)$. | Применить прямые формулы. **(Семинар 9, Задача 1, 3)** | $\text{Cov}(X,Y) = M[XY] - M[X]M[Y]$ <br> $\rho(X,Y) = \frac{\text{Cov}(X,Y)}{\sqrt{D[X]D[Y]}}$ |
| **Дисперсия суммы** | $D[X], D[Y], \text{Cov}(X,Y)$. | $D[X+Y]$. | Использовать формулу для дисперсии суммы. **(Семинар 9, Задача 1)** | $D[X+Y] = D[X] + D[Y] + 2 \cdot \text{Cov}(X,Y)$ |
| **Проверка независимости** | $f(x,y)$, $f_X(x)$, $f_Y(y)$ (или дискретные аналоги). | Независимы ли $X$ и $Y$. | Проверить условие независимости. **(Семинар 9, Задача 2)** | $X, Y$ независимы $\iff f(x,y) = f_X(x) \cdot f_Y(y)$ |

## VII. Задачи на случайную сумму и предельные теоремы

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Математическое ожидание случайной суммы** | СВ $N$ (число слагаемых), СВ $X_i$ (слагаемые), $N$ и $X_i$ независимы. | $M[E]$ для $E = \sum_{i=1}^N X_i$. | Использовать формулу для $M[E]$. **(Семинар 10, Задача 1)** | $M[E] = M[N] \cdot M[X_i]$ |
| **Дисперсия случайной суммы** | $M[N], D[N], M[X_i], D[X_i]$. | $D[E]$ для $E = \sum_{i=1}^N X_i$. | Использовать формулу для $D[E]$. **(Семинар 10, Задача 1)** | $D[E] = M[N] \cdot D[X_i] + D[N] \cdot (M[X_i])^2$ |
| **Оценка вероятности (Неравенство Чебышёва)** | $M[X], D[X]$, отклонение $\epsilon$. | Нижняя граница вероятности $P(|X - M[X]| < \epsilon)$. | Использовать неравенство Чебышёва. **(Семинар 11, Задача 1)** | $P(|X - M[X]| \ge \epsilon) \le \frac{D[X]}{\epsilon^2}$ <br> $P(|X - M[X]| < \epsilon) \ge 1 - \frac{D[X]}{\epsilon^2}$ |
| **Применение ЦПТ** (Сумма/Среднее большого числа СВ) | $n$ велико, $M[X_i] = \mu$, $D[X_i] = \sigma^2$. | Вероятность попадания суммы $S_n$ или среднего $\bar{X}$ в интервал. | 1. Нормировать СВ $Z = \frac{S_n - n\mu}{\sigma\sqrt{n}}$. 2. Использовать функцию Лапласа $\Phi(x)$. **(Семинар 11, Задача 2, 3)** | $P(a \le S_n \le b) \approx \Phi\left(\frac{b - n\mu}{\sigma\sqrt{n}}\right) - \Phi\left(\frac{a - n\mu}{\sigma\sqrt{n}}\right)$ |

## VIII. Задачи на сходимость случайных величин

| Контекст задачи | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм | Ключевые формулы |
| :--- | :--- | :--- | :--- | :--- |
| **Сходимость по вероятности** ($\xrightarrow{P}$) | Последовательность СВ $X_n$, предельная СВ $X$. | Сходится ли $X_n \xrightarrow{P} X$. | Проверить, стремится ли к нулю вероятность отклонения. **(Семинар 12, Пример 1)** | $\lim_{n\to\infty} P(|X_n - X| > \epsilon) = 0$ |
| **Сходимость почти наверное** ($\xrightarrow{п.н.}$) | Последовательность СВ $X_n$, предельная СВ $X$. | Сходится ли $X_n \xrightarrow{п.н.} X$. | Использовать Лемму Бореля-Кантелли. **(Семинар 12, Пример 1)** | $\sum_{n=1}^\infty P(|X_n - X| > \epsilon) < \infty \implies X_n \xrightarrow{п.н.} X$ |
| **Сходимость в среднем $L_r$** ($\xrightarrow{L_r}$) | Последовательность СВ $X_n$, предельная СВ $X$. | Сходится ли $X_n \xrightarrow{L_r} X$. | Проверить, стремится ли к нулю математическое ожидание $r$-й степени разности. **(Семинар 12, Пример 3, 4)** | $\lim_{n\to\infty} M[|X_n - X|^r] = 0$ |
| **Сходимость по распределению** ($\xrightarrow{D}$) | Последовательность СВ $X_n$, предельная СВ $X$. | Сходится ли $X_n \xrightarrow{D} X$. | Проверить сходимость функций распределения $F_n(x) \to F(x)$ в точках непрерывности $F(x)$. **(Семинар 12, Пример 1)** | $\lim_{n\to\infty} F_n(x) = F(x)$ |

## IX. Примеры из семинарских задач: Контекст и Решение

### Пример 1: Дискретная СВ и числовые характеристики (Семинар 9, Задача 1)

| Контекст | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм |
| :--- | :--- | :--- | :--- |
| **Система дискретных СВ** | Таблица совместного распределения $P(X=x_i, Y=y_j)$. | $M[X], D[X], M[Y], D[Y], \text{Cov}(X,Y), D[X+Y]$. | 1. Найти маргинальные распределения $P(X=x_i)$ и $P(Y=y_j)$ суммированием. 2. Вычислить $M[X], M[Y], D[X], D[Y]$ по формулам для дискретных СВ. 3. Вычислить $M[XY] = \sum x_i y_j P(x_i, y_j)$. 4. Найти $\text{Cov}(X,Y)$ и $D[X+Y]$. |
| **Ключевые формулы** | $P(X=x_i) = \sum_j P(x_i, y_j)$ | $M[X] = \sum x_i P(x_i)$ | $M[XY] = \sum x_i y_j P(x_i, y_j)$ | $\text{Cov}(X,Y) = M[XY] - M[X]M[Y]$ | $D[X+Y] = D[X] + D[Y] + 2 \cdot \text{Cov}(X,Y)$ |

### Пример 2: Преобразование непрерывной СВ (Семинар 6, Задача "Сторона квадрата")

| Контекст | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм |
| :--- | :--- | :--- | :--- |
| **Преобразование СВ** | $X \sim U[4,9]$ (равномерное), $Y = \sqrt{X}$. | Функция распределения $F_Y(t)$, плотность $f_Y(t)$, $M[Y], D[Y]$. | 1. Найти $F_Y(t) = P(Y \le t) = P(\sqrt{X} \le t) = P(X \le t^2)$. 2. Использовать $F_X(x) = \frac{x-4}{5}$ для $x \in [4,9]$. 3. Найти $f_Y(t) = F_Y'(t)$. 4. Вычислить $M[Y]$ и $D[Y]$ по формулам для непрерывных СВ. |
| **Ключевые формулы** | $F_X(x) = \frac{x-a}{b-a}$ | $F_Y(t) = F_X(t^2)$ | $f_Y(t) = F_Y'(t)$ | $M[Y] = \int t f_Y(t) dt$ |

### Пример 3: Случайная сумма (Семинар 10, Задача 1)

| Контекст | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм |
| :--- | :--- | :--- | :--- |
| **Случайная сумма** | $E = \sum_{i=1}^N X_i$. $N$ (дискретная) и $X_i$ (непрерывная, $U[3,5]$) независимы. | $M[E]$, $D[E]$. | 1. Найти $M[N], D[N]$ по дискретному распределению $N$. 2. Найти $M[X_i], D[X_i]$ по формулам для равномерного распределения. 3. Применить формулы для случайной суммы. |
| **Ключевые формулы** | $M[X_i] = \frac{a+b}{2}$ | $D[X_i] = \frac{(b-a)^2}{12}$ | $M[E] = M[N] \cdot M[X_i]$ | $D[E] = M[N] \cdot D[X_i] + D[N] \cdot (M[X_i])^2$ |

### Пример 4: Маргинальное распределение и независимость (Семинар 9, Задача 3)

| Контекст | Известно (Дано) | Искомая величина (Найти) | Метод/Алгоритм |
| :--- | :--- | :--- | :--- |
| **Система непрерывных СВ** | Совместная плотность $f(x,y)$ (с неизвестной константой или без). | Маргинальные плотности $f_X(x), f_Y(y)$, проверка независимости. | 1. Найти $f_X(x)$ интегрированием $f(x,y)$ по $y$. 2. Найти $f_Y(y)$ интегрированием $f(x,y)$ по $x$. 3. Проверить, выполняется ли $f(x,y) = f_X(x) \cdot f_Y(y)$. |
| **Ключевые формулы** | $f_X(x) = \int f(x,y) dy$ | $f_Y(y) = \int f(x,y) dx$ | $X, Y$ независимы $\iff f(x,y) = f_X(x) \cdot f_Y(y)$ |

Это руководство создано на основе детального анализа ваших семинарских задач и должно служить прямым инструментом для подготовки к контрольной работе. Оно содержит не только формулы, но и **логику выбора метода** в зависимости от условий задачи.
